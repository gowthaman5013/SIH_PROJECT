Architecture & Real-World Dataset Pipeline Guide

1. Model Architecture (Google MuRIL)

We use google/muril-base-cased fine-tuned with a 10-class Linear Head and independent Sigmoid outputs trained via BCEWithLogitsLoss. Softmax is strictly avoided so multiple indicators can be simultaneously active.

2. Decoupled Text Score

MuRIL predicts 10 raw indicator probabilities. The 0–100 Text Score is computed separately by a normalized weighted sum engine, ensuring model inference remains independent of scoring policy.

3. Replacing Dev Data with Real Data

To train on an approved anonymized dataset, format your CSV with columns: case_id,text,violence,sexual_violence,threat_intimidation,immediate_danger,social_isolation,displacement,family_harm,self_harm_suicidal_ideation,depression_related,legal_distress and re-run python -m src.train.

4. Switching Baseline to IndicBERT

To test IndicBERT, update model_name_or_path = "ai4bharat/indic-bert" in src/config.py and re-train.
